# Hosted replay of Zuo's ordinary-descent result

Run bash run-ordinary.sh in a read-only Linux x86_64 job. Put PrintOrdinary.lean next to the script. Set ORDINARY_AUDIT_LOG_DIR to a dedicated path under the runner temporary directory and upload that directory with the existing artifact action. The script clones the public v1.0.0 tag and rejects any commit other than e632c19bc246b819cd6b882cbf22c2fa9bc453de. It downloads the official SHA-256-pinned Lean 4.33.1 binary and verifies all nine dependency checkout pins via the release driver. Mathlib is 0df444a360eaa60ab8c11dca51a86af692955474. All project sources are built from an empty local tree with warnings as errors. The Mathlib artifact cache supplies dependency objects, and is outside the fresh local build tree.

Build mode is the default. It preserves the release driver's pinned-source, strict-build and axiom checks and skips its additional LeanChecker process per module. Set ORDINARY_AUDIT_MODE=full to run the original bounded driver unchanged, including the separate LeanChecker process for every module. The full mode is a replay with the toolchain's LeanChecker entrypoint. Both modes print the exported definitions and the exact theorem types through Lean after the build, as well as 22 transitive axiom reports. Expected output is 499 strict local builds, the three standard axioms propext, Classical.choice and Quot.sound, and no tracked source changes. There are no Rocq sources in this release.

The runner needs git, curl, GNU tar with zstd, sha256sum, Python 3.11+, and sufficient open-file and memory limits. The upstream hosted configuration calls for 35 GiB free on the audit volume, with about 10 GiB RAM per compiler or replayer and at least 24 GiB for two concurrent jobs. The script preflights the disk and defaults to ORDINARY_AUDIT_JOBS=1. Increase concurrency only on a suitably provisioned runner. Reference per-module timings sum to 9.06 job-hours including separate LeanChecker processes, so a full one-worker replay may miss the six-hour hosted deadline. A timeout, memory kill, volume failure or cache transport failure should be recorded as infrastructure evidence. Only complete success counts as an independent pinned rebuild. On a disposable GitHub-hosted runner, reclaim preinstalled SDK directories such as unused .NET or Android toolchains if needed, or use a larger runner. The entrypoint does not delete unrelated SDKs.

Important output files are formal-audit.log, axioms.log, exported-statements.log, source-revision.txt, toolchain-checksum.txt and release-artifacts.log. The theorem set validates row splitting/multiplicities and fixed-size row mixtures for ordinary descents. The separate consecutive-size conjecture for excedances is outside the Lean conclusion.
