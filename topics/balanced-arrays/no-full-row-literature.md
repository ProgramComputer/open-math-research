# Source and overlap for the no-full-row family

**Screened November 25, 2026.** Per Alexandersson's conjecture asks whether the equal-column-quota array enumerator is real-rooted for every row count, column count and uniform row cap. The cap $r=d-1$ forbids a full row. Complementing entries says that the column subsets cover all row labels. The result here addresses this exact subfamily and also compares consecutive row polynomials. [Author's catalog statement](https://www.symmetricfunctions.com/realRootedOpenProblems.htm#conjBalancedArrays) · [Author's public issue, Open problem](https://github.com/PerAlexandersson/RealRooted/issues/2005)

The first and full caps already have [Jacobi multiplier proofs](finite-linear-reduction.md). The original $U(2,3)$ problem has an [all-row proof](three-column-all-rows.md). The repository's [fixed-rank theorem](fixed-rank-eventual.pdf) gives real-rootedness and consecutive interlacing eventually for each fixed $d$ and $r$, including $r=d-1$. The existing [four-column Mehler reduction](four-column-mehler.md) concerns $r=2,d=4$. It studies a different cap and leaves its all-row conclusion open.

The [independent public investigation](https://github.com/1337isnot1337/solved-conjectures/issues/165#issuecomment-7058747753) already used exact inclusion–exclusion for $r=d-1$ and reported Newton-inequality checks through $d=20$ and $n=100$. It explicitly recorded that no root-preserving diagonal extraction or all-row argument had been obtained. This is overlap on the starting count and search range. The new step here is the Hessenberg determinant with nested totally nonnegative matrices and the multiplier that transfers strict alternation.

The array problem here varies the common column size with the number of rows fixed.
