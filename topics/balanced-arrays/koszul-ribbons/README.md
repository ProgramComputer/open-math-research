# Strongly Koszul balanced arrays and ribbon Schur positivity

For arbitrary hereditary allowed supports on the labeled rows, the quota-graded balanced-array algebra is strongly Koszul over any field. Under the specialization by its weighted quota counts, each ribbon Schur function is a formal multigraded character with nonnegative integer coefficients in the individual cell weights. For a common uniform cap and unit weights, the result also gives nonnegative coefficients in the binomial basis of the variable row count.

The result concerns labeled arrays and applies to the ribbon minors of their quota sequence. General straight and skew minors remain open. The original real-rootedness conjecture for all row counts also remains open. [Original conjecture](https://www.symmetricfunctions.com/realRootedOpenProblems.htm#conjBalancedArrays)

[Hereditary row restrictions can break log-concavity](limitations/README.md), even at unit weights with identical row supports and with a pure flag family. These examples delimit the ribbon positivity argument for the uniform-cap problem.
