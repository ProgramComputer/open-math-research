# Priority screen: a row threshold uniform in dimension at fixed cap

Screen date: 2026-11-26.

The statement proved here is that for every fixed integer $`r\ge1`$ there is an $`N_r`$ such that for all $`n\ge N_r`$ and all integer $`d\ge\max(2,r)`$, $`P_n^{(r,d)}`$ has $`\lfloor nr/d\rfloor`$ simple, strictly negative zeros. Its coefficient of $`q^k`$ counts labelled binary $`n\times d`$ matrices with every column sum $`k`$ and every row sum at most $`r`$. For $`d>nr`$, the degree is zero and the assertion is vacuous. Excluding $`d=1`$ matters for simplicity, since the rank-one one-column polynomial is $`(1+q)^n`$. A uniform threshold gives a finite exceptional range at each individual cap, since at each of the finitely many smaller row counts only $`d\le nr`$ is nonconstant. The threshold remains existential unless quantified separately and may depend on $`r`$.

## Exact prior scope

- The primary SymCat statement asks for real-rootedness at all $`n,r,d`$. The author's issue #2005 was open at the check and had no comments. It describes an unreviewed local eventual simple-negative-root argument only for $`U(2,4)`$, as well as finite rank-two calculations. It supplies neither a varying-dimension statement nor a proof for all $`n`$. [Original conjecture](https://www.symmetricfunctions.com/realRootedOpenProblems.htm#conjBalancedArrays), [author's issue #2005](https://github.com/PerAlexandersson/RealRooted/issues/2005).
- The project's **fixed-pair** theorem gives simple negative zeros and strict consecutive-row interlacing eventually for each fixed proper pair $`1\le r<d`$. It permits a threshold $`N(d,r)`$. It covers every finite set of dimensions by taking a maximum, and supplies the stronger interlacing assertion there, but makes no estimate uniform over unbounded dimensions. [Published theorem at ecd6479](https://github.com/ProgramComputer/open-math-research/blob/ecd64798ac94b6fd81613d1ca6b98ec0d459cb3e/topics/balanced-arrays/README.md), [manuscript](https://github.com/ProgramComputer/open-math-research/blob/ecd64798ac94b6fd81613d1ca6b98ec0d459cb3e/topics/balanced-arrays/fixed-rank-eventual.tex).
- Merged publication PR #89 proves simple negative zeros for $`n\ge N_\varepsilon`$, $`d\ge C_\varepsilon\sqrt{nr/\log n}`$ and either $`r\le n^{1/5-\varepsilon}`$ or $`d\ge n^{3/4+\varepsilon}`$, for each fixed $`0<\varepsilon<1/5`$. At fixed $`r`$, the first disjunct eventually holds and the result covers $`d\ge C_r\sqrt{n/\log n}`$. Together with the fixed-pair theorem it leaves the unbounded windows $`d\to\infty`$ with $`d<C_r\sqrt{n/\log n}`$. A proof on every such sequence would close the uniformity gap by contradiction, using a bounded-$`d`$ subsequence otherwise. [Publication #89](https://github.com/ProgramComputer/open-math-research/pull/89), [versioned package at ba7ddfd](https://github.com/ProgramComputer/open-math-research/tree/ba7ddfd7efb37cac33769f4fdfed749e1b5bf58a/topics/balanced-arrays/dense-regime/rank-dependent).
- The project reports all-row corank one, and for cap fixed this is one dimension. The independent issue #165 remains open, with bounded exact/triage results and no uniform theorem. The project's issue #2 explicitly labels the dimension-uniform assertion an active proof question. [Corank-one publication #50](https://github.com/ProgramComputer/open-math-research/pull/50), [independent issue #165](https://github.com/1337isnot1337/solved-conjectures/issues/165), [project issue #2](https://github.com/ProgramComputer/open-math-research/issues/2).

## Related asymptotics

Greenhill–McKay–Wang Theorem 1.3 and Corollary 5.2 count binary matrices with every margin prescribed under maximum degree product $`st=o(S^{2/3})`$, plus a scaled moment condition for Corollary 5.2. At bounded cap and $`k\asymp n/d`$ near saturation, this degree-product hypothesis is guaranteed by $`d\gg n^{1/3}`$, which leaves many smaller growing dimensions. Canfield–McKay Theorem 1(c) treats very rectangular matrices, with both sides exactly regular, and only describes a saturation profile if $`d\mid nr`$ in this application. Canfield–Greenhill–McKay Theorem 1 and Liebenau–Wormald Theorem 1.1 have size, density, or deviation restrictions that prevent using either for arbitrary growing tall dimensions. Fixed-margin asymptotics supply individual coefficient information, while the theorem needs control of the entire root count across quotas. [GMW final text](https://web.maths.unsw.edu.au/~csg/papers/irregular-final.pdf#page=33), [Canfield–McKay Theorem 1](https://www.kurims.kyoto-u.ac.jp/EMIS/journals/EJC/Volume_12/PDF/v12i1r29.pdf#page=3), [CGM Theorem 1](https://web.maths.unsw.edu.au/~csg/papers/CGM.pdf), [published LW Theorem 1.1](https://onlinelibrary.wiley.com/doi/full/10.1002/rsa.21105).

No independently published proof with the exact dimension-uniform quantifiers, or external full resolution of the original conjecture, surfaced in this screen. The narrower already public results should be credited. This is an access-limited screen, not a definitive priority claim.
