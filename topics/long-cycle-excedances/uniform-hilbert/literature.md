# Prior-art check

**November 26, 2026.** Per Alexandersson's catalog, “Permutations with long cycles,” asks whether the excedance polynomials for permutations with every cycle of length at least $k$ are real-rooted and interlace consecutively for every fixed $k\ge3$. The statement uses excedances. The catalog separately describes the descent-polynomial result and its distinct interlacing question. This package proves a sufficient range for the nonzero excedance roots with the same $k$ in each pair. [Primary statement](https://www.symmetricfunctions.com/realRootedOpenProblems.htm#conjLongCycleExcedances) · [Tracking issue](https://github.com/ProgramComputer/open-math-research/issues/4)

The preceding explicit large-threshold result in this project assumes $k\ge2000\sqrt n(3+\log(3\sqrt{n/k}))$. The previous all-threshold height is $10^{20}$. The present comparison replaces that angular sum of absolute harmonic weights by a signed estimate and supplies the explicit cutoffs $k\ge2000\sqrt n$ and $n\ge10^{18}$ under the stated hypotheses. The recent three-cycle result treats $k\le n\le4k-1$ and concerns a different parameter region. [Earlier large-threshold theorem](../effective-threshold.md) · [Earlier explicit height](../effective-uniform.md) · [Three-cycle proof](../three-cycle-complete.md)

Petuchovas studies the scalar density of permutations without short cycles. Its generating function specializes to the unweighted cycle probabilities that appear here. That paper derives density asymptotics and has no comparison of consecutive excedance roots. [Petuchovas, “Recent results on permutations without short cycles,” published paper](https://ajc.maths.uq.edu.au/pdf/72/ajc_v72_p001.pdf) · [Project's scalar variation estimate](../cycle-probability-variation.md)
