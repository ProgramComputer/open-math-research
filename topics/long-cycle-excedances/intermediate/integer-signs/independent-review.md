# Independent review of the full integer endpoint replay

I reviewed the two sources with SHA-256 `04fcd9029eddd14a3cfd8ac2d6a9b5653e85232e0a7f8ba8979051c96ea72684` (`signs.cpp`) and `3d0f939d8b302c695555f68774b6df81d7d7c1e68b0bcc31e164ed2326d30f0b` (`run.py`). The endpoint test is correct for the canonical #248 archive. This is an exact computational check of the intermediate signs, with Lean verification of the complete replay still outstanding.

## Original coefficients and lag indices

For fixed $`k`$, let $`P_n=E_{n,k}/t`$ on the nonempty range $`n\ge k`$. The first row $`P_k`$ is the Eulerian polynomial of order $`k-1`$, because an admissible permutation at size $`k`$ is one cycle. The descending in-place loop is its Eulerian insertion recurrence and keeps the correct zero coefficients above its degree. At the step from $`n`$ to $`n+1`$, insertion in an existing cycle gives $`(i+1)c_i+(n-i)c_{i-1}`$ at exponent $`i`$ of $`P_{n+1}`$. If $`n\le i`$, the omitted second summand vanishes because of its scalar or because $`c_{i-1}=0`$ above degree $`n-2`$. The constant remains one.

The extra term occurs at $`m=n+1-k\ge k`$ and is $`\binom n{k-1}tA_{k-1}P_m`$. For $`m\lt k`$ neither admissible positive-size lag terms nor the first-row initialization are duplicated. The convolution uses indices $`a`$ and $`i-1-a`$. Its lower bound is exactly the condition $`i-1-a\le m-2`$ and the upper bound enforces $`a\le k-2`$ and $`i-1-a\ge0`$. No product can use an index beyond 59. The ring keeps every lag still needed. At $`m\ge k`$, the lag $`m`$ lies among the preceding $`k`$ sizes and is overwritten only after the step that uses it. The monotonically sorted ledger permits repeated requests at the same pair and then advancing to the next pair, with reinitialization on a new cutoff.

I independently reconstructed the first actual pair, $`k=13`$ and sizes 251 and 252. The recurrence sorts by the support of the cycle containing the least label, with weight $`\binom{N-1}{a-1}tA_{a-1}E_{N-a,k}`$, starting from $`E_{0,k}=1`$. It uses Eulerian coefficients from alternating power sums and FLINT integer convolutions. Both 60-coefficient reduced prefixes matched the C++ output byte for byte. I then applied an independent, homogeneous integer evaluation to those rows, without floor-Horner shortcuts. All 104 signs of the 26 gaps passed. The two JSONL rows have SHA-256 `5458f69b072a2f16ca975e4836bd4cd2e0b0b1b7626dadd7e5fa21398c0daa2e`. I also compared the full 60-slot arrays at sizes 13, 14, 25 and 26, checking the leading ones and all zero upper coefficients around the initial row and the first possible two-cycle contribution. ## Rounding and the geometric remainder

For $`y=p/D`$, $`D=2^b`$, the program requires $`0\lt y\lt 1/2`$. At each alternating Horner step the update is $`c_i-\lfloor y h\rfloor`$. The error from the exact update $`c_i-yh`$ lies in $`[0,1)`$ even if the integer accumulator is negative. Relative to the exact rational evaluation the error is bounded in absolute value by the geometric sum $`1/(1-y)\lt 2`$. Thus the computed signed integer minus two is a strict lower bound on the signed retained evaluation for either sign.

With width $`W=60`$, write $`u=(W+1)^N`$, $`v=(W+2)^N`$. The coefficient envelope $`c_i\le(i+1)^N`$ gives tail ratio at most $`yv/u`$ and first omitted majorant $`u y^W`$. The fast branch writes $`s=b-\operatorname{bitlength}(p)`$, so $`y\lt 2^{-s}`$. Its comparison $`2^s u\ge2v`$ yields ratio below $`1/2`$, and the second shift tests the conservative tail bound $`2u\,2^{-sW}`$. The exact-tail branch requires $`U=Du-pv\gt 0`$. The resulting rational remainder bound is $`u^2p^W/(D^{W-1}U)`$, exactly the cleared denominator in the code. In the final fallback the integer Horner update inserts the factor $`D^{W-1-i}`$ on coefficient $`i`$, yielding the full homogeneous numerator at the same denominator. Every branch asserts a strict margin. Shift arithmetic on the canonical data is comfortably within the unsigned indices. The reported full run used the exact-tail fallback 28 times and never needed the homogeneous fallback.

## Archive pairing and scope

Each record uses lower size $`n`$, cutoff $`k`$, the gap ordinal $`r`$, and exact ordered dyadics. The old sign is $`(-1)^{r-1}`$ at the left endpoint and opposite on the right. The new sign is opposite to the old left sign at both endpoints, as required by the point-separation argument. The upper row powers use size $`n+1`$, including at size 1001. The checker enforces increasing keys, contiguous ranks within each recorded pair, and strict separation of successive brackets in a pair. The expected first/last ranks, eligible empty pairs and completeness come from the earlier independent #248 archive metadata check and from authenticating the entire canonical byte stream, not from the C++ loop alone. [Witness metadata](https://github.com/ProgramComputer/open-math-research/pull/248)

The wrapper checks the decompressed byte count and digest after sending every shard to the checker and observing success. In the reviewed version that final authentication is a Python assertion, so it is bypassed under Python optimization. I recommend changing it to an unconditional error or rejecting optimized Python before publication. The record parser has permissive edges such as a trailing empty field or unsigned narrowing on arbitrary input. Canonical stream authentication makes those irrelevant to this fixed replay. A future extensible checker should reject them at input and limit token lengths before integer shifts.

A fresh local build reproduced the claimed full replay. In 49.91 seconds it verified the canonical 63,014,205-byte archive, 541,199 records across 82,395 nonempty pairs, 2,164,796 signs, 28 exact-tail fallbacks, and zero exact-prefix fallbacks. Its canonical stream SHA-256 was `8f8115d4f203840560dd74f7cf12654d0bca00561c8ff473f27ed6af3f20a73e`. [Packaged replay output](full.log)

## Lean follow-through

The common-pin endpoint theorem already accepts arbitrary exact rational dyadics, cutoff, row size and width. The reusable missing bridge is a soundness proof for this rounded Horner evaluator, plus the two integer tail branches. The invariant can use the strict error bound $`|e|\lt 2`$ inductively: $`|e_{i-1}|\lt 1+y|e_i|\lt 2`$ for $`y\lt 1/2`$. Clearing the common positive denominators then proves the existing rational margin hypothesis, so a separate real-analytic theorem is unnecessary for these arithmetic branches. The coefficient loop also needs a verified relation to the original row or to the already checked exact oracle before porting this replay. The compressed archive should be fed as verified batches. Formal checking of the expected analytic ranks and the non-intermediate joins is separate. No full interlacing theorem is asserted here.
