# Exact linear table for all nine slabs

The Lean definition `linearSlabTable` computes the same table as the (2^{56})-scaled production checker. It uses rational pole weights and integer outward ceilings. The rounding order is the pointwise weight, the division by each odd gap, the maximum finite head, the first-moment tail, the mass and half-tail divisions, and the final bin ceiling. The pole weights are cached once per bin in an array. A Lean lemma identifies that array calculation with the finite sums used in the proof.

The theorem `original_slab_linear_envelope` bounds the linear coefficient of the actual occupied primitives by this table, divided by the scale. It requires (n\ge10000), the slab’s upper aspect condition, positive sine, and (n\sin^2\theta\ge6/5). It applies to every finite pole set, every distinguished index, every truncation and every bin index. The size and sine conditions prove both the floor cutoff and the quarter-rounded angle lower bound. The literal numerator coefficients come from the previously verified probability specification. The proof covers the isolated cutoff atom and uses the exact reflected tail bounds from the existing envelope.

The theorem supplies the linear-envelope input to the rounded product bound without any head, tail, or rounding hypothesis. Its computational comparison checks all 241 entries, including the four initial zeros, in each of the nine slabs. The full determinant comparison and its other quantitative estimates remain separate obligations.
