# A single eventual size for all ordered-partition thresholds

Proposed partial theorem. For each $`n`$ and integer $`j\ge2`$, let $`O_{n,j}(t)`$ count ordered partitions of the labeled set $`[n]`$ by the number of blocks of cardinality at least $`j`$. There exists one integer $`N`$ such that for every $`n\ge N`$ and every $`j\ge2`$ the two rows $`O_{n,j}`$ and $`O_{n+1,j}`$ have only simple negative zeros, and their roots strictly alternate. In order of *increasing modulus*, the new root occurs first in both degree cases. For an unchanged degree the old root occurs last; at an increase the new root occurs last. Empty lists satisfy the corresponding empty comparisons. This gives an existential finite-exception theorem. The conjecture asks for every size including those below $`N`$. [Original statement](https://www.symmetricfunctions.com/realRootedOpenProblems.htm#openProblemsSetPartitions)

Suppose failures occur along old sizes $`n\to\infty`$. Write $`n=mj+s`$, $`0\le s<j`$. Constant polynomials have empty root lists. A carry from degree zero to one has a simple negative zero since both coefficients of the new row are positive. If $`j`$ is bounded on a subsequence, pass to a constant threshold and use the [fixed-threshold eventual result](../all-fixed-thresholds.md). Otherwise pass to $`j\to\infty`$. If $`m`$ stays bounded on a subsequence, the [bounded proportional-window theorem](../proportional-window.md) applies to both sizes, including a carry. Thus we may take $`j,m\to\infty`$.

Choose an old one-based modulus rank $`k`$ involved in the purported failure, including any required neighboring new rank. Concretely, sort each multiset by increasing modulus, breaking ties arbitrarily. At every old rank the desired local claims are simplicity, negativity, $`b_k<a_k`$, and $`a_k<b_{k+1}`$ whenever the latter index exists. Include simplicity and negativity for both named new roots wherever they occur. These claims, if all valid, imply the theorem, so a bad rank can be chosen. Put $`h=m-k`$. If $`h`$ remains bounded use the [uniform fixed-outer-rank result](../outer-ranks/README.md) with two extra ranks. If $`h/m`$ stays bounded below on a subsequence, the [compact root distribution theorem](../growing-outer-ranks/compact-start.md) applies: each prescribed proportion less than one of the smallest-modulus ranks is eventually covered, including its new neighbor. Select a fixed fraction strictly between the upper limit of $`k/m`$ on this subsequence and one. We may therefore take $`h\to\infty`$ with $`h/m\to0`$.

Use the positive coefficient saddle for $`p=m-h`$ large blocks and residual $`s+hj`$. Its variance is comparable to $`m w(1+w)`$ and the saddle mean to $`mw`$, where $`w=r/(1-r)`$. Consequently

$$
\frac{\sigma_h^2}{j^2}\asymp \frac{h}{j}+\frac{h^2}{m}.
$$

After passing to a subsequence, $`j/\sigma_h`$ has a limit in $`[0,\infty]`$. The [sparse two-term argument](sparse.md) covers the infinite limit. The [signed theta-function limit](../growing-outer-ranks/theta.md) covers every positive finite limit. For the zero limit, $`h/j+h^2/m\to\infty`$. Pass again so that $`hj/m`$ either tends to infinity or remains bounded. In the first case $`h^2/m`$ dominates $`h/j`$, so $`h/\sqrt m\to\infty`$ and $`h/(m/j)\to\infty`$. The [moving-pole theorem](../growing-outer-ranks/moving-poles.md) applies. In the bounded case $`h/j`$ dominates up to a constant, hence $`h/j\to\infty`$, and the [bounded-radius dense argument](dense.md) applies. All four arguments include the prescribed neighboring ranks across a carry and establish ranks among *all* complex roots. This rules out the chosen failure.

Finally, potential exceptional parameter pairs really are finite: below the asserted $`N`$, each $`j>n+1`$ gives two constant rows. The proof does not compute $`N`$. A finite check through any separately chosen limit therefore does not by itself settle the all-size conjecture.
