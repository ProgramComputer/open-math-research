# Source and scope comparison

The ordered set partition problem is Alexandersson’s 2026 conjecture in the “Set partitions and trees” section of SymCat. Blocks are ordered, every block of size at least $`j`$ receives one mark, and the comparison is between consecutive sizes at fixed $`j`$. The catalog reports a finite test for $`j\le5`$, $`n\le30`$. The proposed theorem in this package gives one eventual size for all $`j`$ and all ranks, with strictness and simplicity. It leaves the all-size question open. [Conjecture and exponential generating function](https://www.symmetricfunctions.com/realRootedOpenProblems.htm#openProblemsSetPartitions)

The external solved-conjectures project reports two edge results at each fixed threshold. Its November 26 right-edge argument covers a positive fraction of real zeros and identifies the first fixed-rank spacings. Its separate left-edge argument treats any fixed number of largest-modulus roots, with residue-class-dependent leading constants. The threshold on the row size in both results may depend on the fixed parameters. Both notes explicitly describe the remaining middle-root question. The author's RealRooted project also records the broader classification problem for marked block weights. [Right-edge argument at f1a5ac2](https://github.com/1337isnot1337/solved-conjectures/blob/f1a5ac298febcfd20b19e1ef3465325eb62e18d6/research/alexandersson-ordered-set-partitions/edge.md) · [Left-edge argument at e39bd01](https://github.com/1337isnot1337/solved-conjectures/blob/e39bd018c0f980ff394daa7764272226890c6d14/research/alexandersson-ordered-set-partitions/left-edge.md) · [External issue history](https://github.com/1337isnot1337/solved-conjectures/issues/108) · [Weight classification question](https://github.com/PerAlexandersson/RealRooted/issues/2590)

Chengyi Fang's November 26 preprint studies ordinary set partitions counted by blocks of size at least four. Its exponential generating function is the exponential of a block series. The ordered enumerator uses the reciprocal of one minus the block series. Fang's different statistic and hypotheses are visible in the definition and Theorem 1 on page 1. The Ahlberg–Alexandersson weighted renewal theorem also uses a reciprocal series. It requires the coefficient of the mark to occur with specified lengths in $`1/(1-zR(tz^\ell))`$, with $`R`$ a finite real-rooted polynomial. Marking every sufficiently large block in the exponential block series allows infinitely many sizes for the same mark. [Fang, version 1](https://hexagonmath.org/pdf/2611.01129v1) · [Weighted renewal theorem and proof](https://www.symmetricfunctions.com/realRootedInterlacing.htm)
